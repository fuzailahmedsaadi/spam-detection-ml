# 📧 Spam Detection using Machine Learning

## 🔍 Overview
This project classifies SMS messages as **Spam** or **Ham** using NLP and Machine Learning.

## 📂 Dataset
SMS Spam Collection Dataset

## ⚙️ Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- TF-IDF
- Multinomial Naive Bayes
- Streamlit

## 📊 Results
- Accuracy: ~96%
- High spam precision
